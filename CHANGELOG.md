# Changelog

All notable changes to Potato Region are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.1.1] - 2026-10-19

### Fixed

- Play together can reach a friend on another network. The farm party keeps its code if the iPad screen goes dark, and a guest is told to check the code instead of waiting forever.

## [1.1.0] - 2026-10-18

### Added

- Play together, a two to four player farm party in the browser.
- A picture code, a four-digit code, and a QR code so a friend can join.
- Smooth painted friends, with planting, watering, harvesting sparkles, and heart, wave, and potato-dance emotes.
- A gentle reconnect when a connection takes a nap, and a way back to playing alone.

## [1.0.0] - 2026-10-18

### Added

- Potato Region, a quiet farming game for the iPad Home Screen.
- Eight colour farms: blue, green, red, purple, pink, orange, turquoise, and lilac.
- Potato Trade Deals, where potatoes are counted onto the counter.
- Dress-up clothes, hats, and pets, including the blue strap dress, green headband, and yellow chihuahua.
- A house that remembers furniture you place, move, and put away.
- Read-aloud words, local save, and Tell us notes for grown-ups.
- In-place updates with an Update ready banner on the region map.
- A What's new screen and version v1.0.0.
